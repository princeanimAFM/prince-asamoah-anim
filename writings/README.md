# Writings for the book

Prince's reflections on faith, theology and life's big questions, first shared as card sets on his
personal TikTok (@princeanimafm). Each piece is kept here, in order, so they can later be gathered
into a book.

Each folder holds one piece:
- `notes.md`: the full text in Prince's own words, with only grammar tidied, plus the scriptures used.
  This is the version to build the book from.
- `post.md`: how it was posted: the card-by-card text, the caption, the date and the music.
- `cards.html` and `cards/`: the designed cards (1080×1920). Open `cards.html` in a browser to see or
  re-export them.
- Any originals: notebook photos and song recordings.

Scripture quotations are from the King James Version (public domain).
